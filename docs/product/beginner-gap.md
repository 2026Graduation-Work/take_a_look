# 초보 투자자 문제 ↔ 우리 기능 점검 (2026-10-09)

초보 개인투자자가 실제로 어려워하는 점을 공개 자료로 정리하고, 우리 기능이 그 문제를 푸는지 **운영 화면을 직접 열어** 판정했다.

- 운영 확인: `https://takealook-skku.vercel.app`, 데모 → "데모 응답"(추종형) 설문 → 예시 보유 4종목. 대시보드와 상세 4종목(005930·005380·068270·035720) 화면 텍스트를 Playwright로 읽었다. 데이터 기준일은 10/08(최신 게시).
- 해결 정도: **충분**(문제를 직접 다루고 실데이터·정확) / **부분**(일부만, 또는 정확성 문제) / **없음**.
- 우리 원칙상 매수·매도를 권하지 않는다(HITL). "해결"은 판단을 대신하는 것이 아니라 **판단 전에 확인할 것을 보여 주는 것**이다.
