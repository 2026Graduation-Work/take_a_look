## 이번 원본 내보내기 결과

`experiments.export_oos`로 `run_id=a6723ca89a07fbe5`의 2019~2025 H5/H20 A 예측을 내보냈다. 출력 폴더는 chart 디렉터리 기준 `workspace/experiments/exports/psychology_ab_2019_2025_oos_20261020/`다. [명령과 열 정의](../../backend/analysis/chart/experiments/README.md)를 참고한다.

| 파일 | 전체 예측 행 | 라벨과 수익률 관측 행 | 미래 관측 미확정 행 |
|---|---:|---:|---:|
| `h5_A.parquet` | 1,291,240 | 1,290,408 | 832 |
| `h20_A.parquet` | 1,291,240 | 1,289,884 | 1,356 |

고정된 피처 입력에서 원래 배리어 라벨을 다시 계산해 관측 여부와 라벨을 전수 대조했다. 불일치는 0건이다. 거래정지일을 건너뛴 종가 수익률을 별도로 붙였으며, 원래 예측과 라벨을 수정하거나 미확정 행을 제거하지 않았다.

파일 해시는 `manifest.json`에 있다. H5 SHA-256은 `a93d6a2c4f191a4ecb8cc54158f23b77a5d83a00ea39b4b1bdb4a5c8ae0b7343`, H20은 `dbaa0cd2c21253597311c922c1c1475de7ebc32b45581cff80f1e36d3e1fe588`이다. 원본 두 파일은 합계 약 103MiB이며 로컬에만 있다. 이 PR만으로 다른 PC에 원본이 전달되지는 않는다.

실행 당시 H5 라벨 배수는 상방 1.75σ, 하방 1.5σ이고 H20은 3.75σ, 3.0σ다. 현재 운영 기록 설명의 1.5σ, 1.2σ와 다르므로 두 결과를 같은 라벨 기준의 성적으로 합치지 않는다. 수익률은 비용을 반영하지 않은 신호일 종가 기준이며 전략 수익률을 뜻하지 않는다.

로컬 검증은 저장 파일 변조와 기존 출력 덮어쓰기 거부, 거래정지와 미확정 관측, 원래 라벨 대조를 포함한다. 새 테스트 7개를 포함해 chart 전체 322개가 통과했고 기존 샘플 processed 파일이 없는 3개는 건너뛰었다. 저장소 ruff 검사, `git diff --check`, 프론트 빌드도 통과했다. 원격 DB와 브라우저 E2E는 이번 내보내기에서 확인하지 않았다.

## 현재 포함하지 않는 작업

새 모델 학습, 원격 데이터 재수집, 원격 DB 변경, 운영 pack 교체, 정기 실행 설정 전환은 이번 원본 내보내기에 포함하지 않는다. 연구 원본과 복구 데이터, 기존 모델은 보존한다.

코드 변경은 새 브랜치에서 로컬 검사 후 PR, 봇 리뷰, 필수 체크를 거쳐 셀프 머지한다. 운영 경로 변경은 별도 보안 점검과 해당 예비 실행이 필요하며, 운영 배포는 담당자 확인 뒤 진행한다.
