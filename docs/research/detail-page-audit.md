# 종목 상세 페이지 점검표 — 보는 순서와 설명 수준

작성일: 2026-10-20. 계기는 10/19 지도교수님 면담 피드백 ③입니다. "초보 투자자에게 보여 주는 순서와 설명 수준(특히 PC 상세 페이지)."

**이 문서는 팀 합의용 근거 자료입니다.** 코드는 바꾸지 않았습니다. 서환의 #360(상세 페이지 색과 글자 계층)이 열려 있어, 그 결정을 그대로 둔 상태를 기준으로 봅니다. 고칠 내용은 모두 '제안'입니다.

대상 코드는 `frontend/app/components/stock-detail.tsx`, `insight-cards.tsx`이고, 운영 화면은 `/stocks/005930`(데모 계정)입니다.

## 표시한 곳

**A. 1280에서 늦게 읽히는 핵심 정보: 헤더 오른쪽**
- F자 시선 패턴(NN/g)에서 첫 줄은 왼쪽에서 오른쪽으로 훑지만, 그 아래부터는 왼쪽 끝을 따라 내려갑니다.
- 보유 수량과 평단 대비 손익은 오른쪽 13px 흐린 글자라, 보유자에게 가장 궁금한 숫자가 가장 늦게 읽힙니다.
- 제안: 보유 중일 때는 '내 보유' 한 줄을 이름 아래(왼쪽)로 옮기거나, 4번 카드의 결론 문장 바로 아래에 둡니다.

**B. 결론보다 행동 버튼이 먼저**
- 관심 종목과 메모 버튼(3)이 모델 신호 결론(4)보다 위에 있습니다.
- 제안: 버튼 줄을 4번 카드 아래로 내립니다. 결론을 읽고 나서 하는 행동입니다.

**C. 제목보다 보조 문구가 먼저**
- 6번 섹션에서 13px "판단 근거 4가지, 내 성향에 맞춘 순서"가 20px 제목 위에 있습니다.
- 화면 규칙 0장("부제, eyebrow 라벨은 기본적으로 없다")과도 어긋납니다.
- 제안: 보조 문구를 제목 아래로 옮기거나 지웁니다. '내 성향에 맞춘 순서'는 탭 옆 ⓘ로 옮깁니다.

**D. 비교 기준 없이 절대값만 있는 숫자**

| 탭 | 숫자 | 지금 | 제안하는 비교 기준 |
|---|---|---|---|
| 재무 상태 | PER 27.9배, PBR 2.9배, ROE, 영업이익률, 부채비율, 매출 증가율 | 값만 | 코스피 중앙값 또는 같은 업종 중앙값 대비("코스피 절반보다 높은 편") |
| 누가 사고팔았나 | 순매수 +262.3만 주 | 주 수만 | 같은 기간 거래량 대비 %, 또는 상장주식 대비 % |
| 시장 분위기 | 가격 흔들림 n% | 코스피 상위 N% ✓ | 이미 있음 |
| 한눈에 보기 | 수익률 범위 | 과거 비슷한 경우 ✓ | 이미 있음 |

진세가 #360에서 말한 '재무에서 절대 수치보다 상대 비교'와 같은 지점입니다. 재무 비교에는 코스피 종목별 재무 지표 분포가 필요해 데이터 작업이 따릅니다.

**E. 라벨 안 괄호 설명 → ⓘ로 가야 할 내용**
- 재무 지표 라벨 6개는 정의가 라벨에 붙어 있어 한 줄이 길어지고, 390에서 줄바꿈됩니다. 예: "PER(주가가 1년 이익의 몇 배인지)", `copy-glossary.ts`의 `FINANCIAL_TERM`.
- 시장 분위기의 "가격 흔들림(1년, 코스피 상위 N%)"은 정의와 비교 기준이 섞여 있습니다.
- 제안: 라벨은 'PER'처럼 짧게 두고 정의는 ⓘ(누르면 열림, 화면 규칙 v2 ⓘ 규칙)로 옮깁니다. 비교 기준은 값 옆 13px로 둡니다.

**F. 네 탭 중 일부에만 있는 요소**

| 요소 | 시장 분위기 | 누가 사고팔았나 | 모델이 본 이유 | 재무 상태 |
|---|---|---|---|---|
| 결론 문장 | ✓ | ✓ | ✓ | ✓ |
| 왜 봐야 하나요? | ✓ | ✓ | ✓ | ✗(#359에서 의도적으로 뺌) |
| 접어 둔 계산 근거 | ✗ | ✗ | ✓(계산값 보기) | ✓(계산 근거) |
| 기준일 각주 | 오래됐을 때만 | ✓ | — | ✓(계산 근거 안) |

- '왜 봐야 하나요?'를 다시 둘지는 팀 결정이 필요합니다. 진세는 다시 두자는 의견이고, 서환은 깔끔하게 하려고 뺐습니다.
- 제안: 네 탭에 모두 두되, 지금처럼 설명 문장 대신 '이 숫자를 무엇과 비교해 보면 되는지' 한 줄로 바꿉니다. D의 비교 기준과 같은 내용이라 중복 없이 채울 수 있습니다.

## DESIGN.md 펼치기 규칙의 예외 제안

화면 규칙 v2의 펼치기 규칙은 "기본은 다 보여 준다. 항목이 많을 때만 처음 3개 + 더 보기. 펼침 안 펼침 금지"입니다. 지금 상세 페이지는 이렇습니다.
- '더 알아보기'(통째로 접힘), 재무 '계산 근거', 모델 이유 '계산값 보기', '다른 유형이라면?'이 접혀 있습니다.
- 결과적으로 4단 내용이 세 곳에 흩어져 접혀 있습니다.

제안은 다음 한 줄을 v2 표에 예외로 추가하는 것입니다.

> **4단(방법과 계산 근거)은 접어 둔다.** 블록마다 맨 아래 하나의 접기로만, 이름은 '계산 근거'로 통일, 접기 안에 또 접기는 두지 않는다.

이렇게 하면 '더 알아보기' 안의 계산 근거와 탭 안의 계산 근거가 같은 이름, 같은 위치가 되고, 1~3단은 늘 펼쳐 둡니다.
