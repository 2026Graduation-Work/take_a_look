## 2. 새 지표 (`experiments/evaluation/metrics.py`)

| 함수 | 내용 |
| --- | --- |
| `daily_rank_ic` | 날짜별 단면 Spearman. 기존 `calculate_rank_ic`도 이 함수를 쓰며 출력은 그대로다 |
| `summarize_daily_ic` | 평균, 표준편차, ICIR(평균/표준편차, 일 단위, 연율화하지 않음), 양(+)인 날 비율 |
| `top_bottom_spread` | 날마다 점수 상위 10% 평균 수익률 − 하위 10% 평균 수익률의 날짜 평균. 비용 미반영 |

읽는 법
- 실제 수익률 기준 IC는 라벨 기준 IC(H5 0.067)보다 낮다. 라벨은 세 칸으로 뭉개진 값이라 같은 모델이라도 숫자가 다르다. 앞으로 비교는 수익률 기준 IC로 한다
- 초과수익 IC가 원 수익률 IC와 거의 같은 건 정상이다. 같은 날 모든 종목에서 같은 KOSPI 수익률을 빼므로 순위가 바뀌지 않고, 거래정지로 끝나는 날이 다른 종목만 조금 달라진다. 종목 사이 순위 지표에서는 초과수익 버전이 정보를 더하지 않는다
- H20/2020은 IC는 양수인데 상위−하위 차이가 음수다. 순위 전체로는 맞았지만 양 끝 10%에서 틀렸다는 뜻이라 두 지표를 함께 본다
