# 심리지표 후보 실험 (P1~P5)

작성일: 2026-11-25. 코딥(Co-Deep 2026-2) 실험이다.

## 왜

[심리 피처 A/B](../psychology-ab-2019-2025/README.md)에서 심리 지표 4개를 더한 B는 수익률 순위를 개선하지 못했다(#447 E0: 날짜별 Rank IC 차이 1주 −0.0006, t −1.96 / 4주 +0.0003, t 0.93). 4개 모두 각 종목의 종가와 거래량으로만 계산해서, 같은 데이터에서 나온 기존 피처 170개와 겹칠 수 있다. 그래서 심리를 예측에 쓸 다른 방법 다섯 가지를 모두 시험하고, 결과에 따라 섞거나 하나를 고른다(사용자 결정, 11/25). 모두 안 되면 "심리는 분류와 안내에 쓰고 모델 학습에는 쓰이지 못했다"고 쓰고, 심리 밖의 개선 방법(E1~E7)을 제안한다.

| 후보 | 내용 |
| --- | --- |
| P1 | 가격 밖의 정보로 심리를 잰다: 뉴스, 검색량 같은 관심도, 투자자예탁금과 신용잔고 |
| P2 | 시장 심리 × 종목 특성. 심리가 뜨거울 때 가치를 매기기 어려운 종목이 이후 부진하다는 연구(Baker & Wurgler, 2006) |
| P3 | 공포, 탐욕 국면에 따라 모델 신호의 신뢰도가 다른가 |
| P4 | 방향 대신 위험(앞으로의 변동성)을 맞힌다 |
| P5 | 효과가 나타나는 기간에 맞춘다(과잉반응은 며칠, 처분효과는 몇 달) |

API가 주는 가장 이른 기준일은 신용공여 **2021-11-09**, 증시자금 **2021-10-26**이고 마지막은 2026-11-24다(조회 시작일을 1900-01-01로 줘도 이 날짜부터 온다). 원본 JSON은 Drive `Take a Look Data Storage/P1_kofia/`에 두었고 sha256이 로컬과 같다. 네이버 데이터랩은 2026-07-31부터 신규 신청이 NAVER API HUB(NCP 계정)로 옮겨져 무료 원칙상 보류한다.

**방법.** 시장 값은 같은 날 모든 종목에 같아서 그대로는 순위를 바꾸지 못한다. 그래서 P2와 같이 날짜별 "종목 특성의 IC"(특성 순위와 미래 수익률 순위의 상관)를 시장 심리 z로 회귀한 기울기를 본다. 함께 적은 상호작용 IC는 z × 특성의 날짜별 IC로, 그날 z의 부호로 특성 방향을 뒤집은 값과 같다.
- 시장 심리 3개: 신용융자(유가증권) ÷ 시가총액(KOSPI 지수로 근사), 투자자예탁금 20일 변화율, 신용융자 20일 변화율. 각각 직전 250일(최소 120일) 평균과 표준편차로 z를 만들고, 공개 시차를 고려해 2거래일 전 값을 쓴다
- 종목 특성 2개: 60일 변동성, 개인 순매수 쏠림. 개인 순매수 자료가 없어 쏠림은 A/B 때의 `psych_herding`(거래량이 실린 날의 방향 쏠림)으로 대신했다
- 평가 행: 투자 가능 집단([모델 개선 계획](../model-improvement-plan.md) 3절), 표본 밖 예측 행의 1주, 4주 수익률

읽는 법
- **신용융자가 빠르게 늘 때 변동성 큰 종목이 이후 덜 오른다.** 두 기간, 두 구간에서 같은 방향이다. 빚을 낸 매수가 몰릴 때 흔들리는 종목이 고평가된다는 Baker & Wurgler(2006)의 방향과 맞고, P2에서 KOSPI 공포·탐욕으로 본 결과(탐욕일 때 변동성 큰 종목 부진)와도 같은 방향이다
- 신용융자 수준(÷ 시가총액)은 구간마다 방향이 바뀌어 믿기 어렵다. 변화율이 수준보다 낫다
- 투자자예탁금과 쏠림은 정보가 약하다
- 검정 24개 중 2개다. 확인 구간 기울기 t는 −1.8, −1.2라 강하지 않고, 확인 구간 상호작용 IC t(−2.9, −2.2)가 더 강하다. 2단계에서는 ④(시장 심리 × 변동성)와 같은 방식으로 z(신용융자 20일 변화) × 60일 변동성 백분위를 후보 피처로 더하는 것을 검토한다. 자료가 2021-11부터라 2019~2021 학습 구간에는 값이 없다는 제약이 있다
