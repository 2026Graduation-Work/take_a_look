# AI 페르소나 인지적 워크스루 (2026-10-13)

> **이 문서는 실제 사용자 테스트(#272)를 대신하지 않는다.** AI가 페르소나를 정해 화면 텍스트만 보고 과제를 수행해 본 점검이다. 실제 사람의 이해·신뢰·만족은 #272 세션에서만 잰다. SUS 같은 실사용자 점수는 여기서 만들지 않는다.

## 방법

- **대상**: 운영 사이트 https://takealook-skku.vercel.app (2026-10-13 01~03시 KST, 데이터 기준일 2026-10-08 — 차트 게시가 #296으로 멈춘 상태)
- **도구**: Playwright 스크립트. 페르소나마다 새 브라우저 컨텍스트(시크릿과 같음)에서 시작
- **공정성 규칙**: 워크스루 중에는 코드를 읽지 않고 화면 텍스트(`innerText`·접근성 이름)만으로 판단했다. 시작 주소 외에는 주소를 직접 치지 않았다. 원인 분석은 워크스루가 끝난 뒤 코드로 했다
- **판정**: 성공 / 망설임 / 막힘 / 오해. 심각도는 Nielsen 0~4(0 문제 아님 · 1 겉모습 · 2 작음 · 3 큼 · 4 치명)
