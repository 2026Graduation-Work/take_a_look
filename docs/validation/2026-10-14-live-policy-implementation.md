## PR 피드백 반영: 짧은 UX 안내와 내부 구성 통계

기업·산업·시장 기사의 기존 종합 평균을 유지한다. 화면에서 기업 자체 감성으로 오해하지 않도록, 새 필터 대상 6종목의 Live 결론을 “종목 관련 뉴스 분위기”로 표시하고 “기업 소식과 관련 산업·시장 뉴스를 함께 반영합니다.”를 한 줄로 안내한다. 과거 데이터·기타 종목은 이 설명을 표시하지 않는다. 화면 배치와 기존 수치는 유지하고 분류별 숫자는 노출하지 않는다.

`live_news_sentiment_breakdown` JSON 로그에는 정책 버전, 회사, 판정별 건수와 포함 분류(direct/indirect/industry/market)별 기사 수·감성 평균을 기록한다. 해당 분류 기사가 없으면 평균은 null이다. 뉴스 실행·Supabase 동기화 CLI에서 INFO 로그를 활성화하여 실행 로그로 확인할 수 있다. 본문·기사별 감성·인증 정보는 이 진단 로그에 넣지 않는다. 결과 track·기사 DB 필드는 추가하지 않는다.
