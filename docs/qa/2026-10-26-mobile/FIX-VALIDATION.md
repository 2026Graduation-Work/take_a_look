## 자동 검증

- 새 모바일 회귀 13개 + 기존 기간 전환 1개 + 설명 열기/닫기 3개: **17/17 통과** (`TAL_SENTIMENT_E2E=1`).
- 기존 상세·보유 저장·메모·보유 맵·헤더·터치 영역·계산 근거 회귀: **31/31 통과**. 설명 테스트는 별도 위 3개로 재검증했다.
- 설명 키보드 테스트는 페이지 전환 직후 Tab을 시작하던 경합을 제거하기 위해 트리거 표시를 기다리도록 변경했다.
- 기존 기간 전환 fixture는 공개 응답에서 누락된 카카오 신호를 예시 데이터로 채우는 동작에 의존했다. 네 보유 종목의 공개 응답을 명시하고 로딩 완료 뒤 배치를 비교하도록 고쳤다.
- 단위 테스트 **178/178 통과**, `pnpm lint` 통과, `pnpm build` 통과. 실행에는 프로젝트에 고정된 `corepack pnpm`을 사용했다.
- 독립 코드 리뷰에서 찾은 계정 보유 종목 조회 누락·빈 결과 요약·저장소 쓰기 실패·검색 행 기간 고정을 수정하고 재검증했다. 최종 리뷰에서 추가 중요 결함은 보고되지 않았다.

## Computer Use로 로컬 빌드 확인

Chrome의 390×844/320×844 CSS viewport로 <http://localhost:3100/>의 프로덕션 빌드를 확인했다. API 직접 호출이나 브라우저 저장소 주입 없이 새 데모 → 데모 설문 → 보유 등록 → 대시보드 → 상세를 조작했다. 실제 계정의 개인 보유 정보는 사용하지 않았다.

- M01: 온보딩에서 SK하이닉스 검색 → Enter → 000660 행 생성 → 가상 수량 2주 입력 → 저장 성공.
- M02: 삼성전자 1주 하락 타일 → 상세 1주 하락과 H5 범위 -8.0%~+8.3% 확인. 상세에서 4주로 바꾸면 상승과 H20 범위 -14.5%~+20.4%로 변경되고, 대시보드로 돌아가도 4주 선택 유지.
- M03: 320px에서 SVG 축·날짜 글자 `font-size=13`, 렌더링 박스 높이 15.5px 확인. 강조 글자 `font-size=14`, 박스 높이 17px. 과거 구간은 차트 내부 가로 스크롤로 탐색한다.
- M04: 대시보드 최초 진입에 로딩 안내가 보이고, 조회 후 공개 종가 기반 평가금액(삼성전자 가상 15주 약 320만원 등)이 표시됨. 강제 지연·오류·빈 응답은 위 자동 검증에서 확인했다.
- M05: 개인정보 처리방침의 데모 삭제 범위에 네 항목이 모두 표시됨.
- M06: 366개 점을 가진 실제 전체 기간 감성 차트에서 최신/과거 점 클릭. 최신 툴팁 x=40~310.21px, 보이는 차트 x=40~335px로 내부에 위치. Escape로 닫힘 확인.

## 범위와 한계

브라우저 자동화의 데이터 오류·지연 검증에는 테스트 응답을 사용했다. 실제 iOS/Android 기기, 소프트 키보드, 실사용자 계정은 검증하지 않았다. 원래 체크아웃의 미커밋 작업을 새 작업 공간에 섞지 않았다. 이 문서는 로컬 수정 검증이며 배포 완료를 뜻하지 않는다.
