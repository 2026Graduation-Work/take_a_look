# 대표 결과

수급 포함 H5/H20 모델을 로컬 serving에 연결한다. 마지막 fold의 학습 기간은 **2023-01-01~2025-12-31**, OOS 예측은 **2019~2026-10-06**이다. 입력은 기본 161개와 수급 9개, 총 170개 피처다. 수급 피처는 개인·기관·외국인의 1/5/20거래일 순매수 거래대금을 같은 기간 전체 거래대금으로 나눈 값이다. 최근 완료된 모델을 재사용하며 추가 튜닝하지 않았다.

| 모델 | 2019~2025 연도 수익률 단순평균 | 최악 연중 MDD | 2026-10-06까지 수익률 |
|---|---:|---:|---:|
| 수급 H5, 현재 활성 | +13.02% | -12.91% | +2.89% |
| 수급 H20, 현재 활성 | +3.96% | -14.98% | +7.56% |
| 기본 H5, 이전 pack 보존 | -2.61% | -57.33% | +10.01% |
| 기본 H20, 이전 pack 보존 | -3.37% | -56.36% | +21.92% |

출처: 보존된 `workspace/experiments/runs/kospi_backtest_report_2026-10-09.md`와 기본·수급 H5/H20 run의 `backtest_metrics_by_year.csv`.

각 연도는 시작 자금 1,000만 원으로 독립 실행했다. 표의 평균은 CAGR이나 연속 운용 누적 수익률이 아니다. 2026은 부분 연도다. 같은 2026 평가 거래일의 KOSPI 가격지수 수익률은 +64.72%이며 배당을 포함하지 않는다.

종목별 상방 스코어 0.65 이상 중 일별 최대 5개 신호, 다음 거래일 시가 진입, 매수·매도 각각 0.105% 비용, 정수 수량 버림을 사용했다. 가용 현금의 1/5이 신규 주문 한 개의 예산이며 동시 보유 5종목 상한은 아니다. 슬리피지·충격 비용·체결 지연은 모델링하지 않았다. 상세 실행 규칙과 연도별 결과는 원문 보고서에 보존했다.

수급 결측 때문에 기본·수급 모델의 평가 표본이 다르므로 차이를 수급 피처만의 효과로 해석할 수 없다. 수익률이 모델의 우월성을 입증하지 않는다. [품질 제한](DATA_QUALITY.md)을 함께 적용하고, 모델 출력은 사용자가 판단할 근거 중 하나로 제시한다.
