# 대표 결과

수급 포함 H5/H20 모델을 로컬 serving에 연결한다. 마지막 fold의 학습 기간은 **2023-01-01~2025-12-31**, OOS 예측은 **2019~2026-10-06**이다. 입력은 기본 161개와 수급 9개, 총 170개 피처다. 수급 피처는 개인·기관·외국인의 1/5/20거래일 순매수 거래대금을 같은 기간 전체 거래대금으로 나눈 값이다. 최근 완료된 모델을 재사용하며 추가 튜닝하지 않았다.

| 모델 | 2019~2025 연도 수익률 단순평균 | 최악 연중 MDD | 2026-10-06까지 수익률 |
|---|---:|---:|---:|
| 수급 H5, 현재 활성 | +13.02% | -12.91% | +2.89% |
| 수급 H20, 현재 활성 | +3.96% | -14.98% | +7.56% |
| 기본 H5, 이전 pack 보존 | -2.61% | -57.33% | +10.01% |
| 기본 H20, 이전 pack 보존 | -3.37% | -56.36% | +21.92% |

출처: 보존된 `workspace/experiments/runs/kospi_backtest_report_2026-10-09.md`와 기본·수급 H5/H20 run의 `backtest_metrics_by_year.csv`.

각 연도는 시작 자금 1,000만 원으로 독립 실행했다. 표의 평균은 CAGR이나 연속 운용 누적 수익률이 아니다. 2026은 부분 연도다. 같은 2026 평가 거래일의 KOSPI 가격지수 수익률은 +64.72%이며 배당을 포함하지 않는다.

종목별 상방 스코어 0.65 이상 중 일별 최대 5개 신호, 다음 거래일 시가 진입, 매수·매도 각각 0.105% 비용, 정수 수량 버림을 사용했다. 가용 현금의 1/5이 신규 주문 한 개의 예산이며 동시 보유 5종목 상한은 아니다. 슬리피지·충격 비용·체결 지연은 모델링하지 않았다. 상세 실행 규칙과 연도별 결과는 원문 보고서에 보존했다.

수급 결측 때문에 기본·수급 모델의 평가 표본이 다르므로 차이를 수급 피처만의 효과로 해석할 수 없다. 수익률이 모델의 우월성을 입증하지 않는다. 아래 품질 제한을 함께 적용하고, 모델 출력은 사용자가 판단할 근거 중 하나로 제시한다.

## 품질 제한

데이터 종료일은 **2026-10-06**이다. 2026 OOS·백테스트·과거 사례는 부분 연도이며, H5/H20 후속 관측이 끝나지 않은 행은 사례에서 제외한다.

1. 수정가격은 현재 공급자 snapshot이다. 당시 시점의 수정계수 기록을 완전히 재현한 point-in-time 자료가 아니다.
2. 과거 KOSPI 구성 이력은 완전히 검증되지 않았다. 상장·상폐 구간을 적용해도 전체 역사적 구성종목 재현을 보장하지 않는다.
3. KRX 거래대금·거래량의 집계 범위는 미확인이다. OHLC 범위를 벗어난 VWAP을 강제 보정하지 않고 건수·날짜를 기록한다.
4. `RegularSessionUnavailable`은 정규장 OHLC 미관측 사실이다. 정규화의 `Trading_Halt` 실행 제외 표시와 구분한다. 원본 `RawVolume`·`Amount`는 남기고 실행용 `Volume`만 0으로 둔다. 공식 거래정지를 입증한 표시로 해석하지 않는다.
5. 수급 ranking의 미반환·부분 응답은 결측이다. 0으로 채우지 않는다. 현재 로컬 serving의 수급 H5/H20은 필요한 9개 수급 입력 중 하나라도 결측이면 해당 종목·기간의 추론을 제외한다. 기본 모델과 평가 표본이 달라 직접적인 효과 비교에 제한이 있다.

거래일 누락·불명확한 가격 결측은 추정 거래정지나 0으로 바꾸지 않고 거부한다. 정량 출력은 결정론이며 스코어·기여도·과거 사례는 미래 수익 보장이 아니다. 재점검 신호는 **매도 지시가 아님**을 화면에 함께 표시한다.

제한별 실제 제외 건수는 [local-pack-validation.json](local-pack-validation.json)에 있다.
