# 현재 품질 제한

데이터 종료일은 **2026-10-06**이다. 2026 OOS·백테스트·과거 사례는 부분 연도이며, H5/H20 후속 관측이 끝나지 않은 행은 사례에서 제외한다.

1. 수정가격은 현재 공급자 snapshot이다. 당시 시점의 수정계수 기록을 완전히 재현한 point-in-time 자료가 아니다.
2. 과거 KOSPI 구성 이력은 완전히 검증되지 않았다. 상장·상폐 구간을 적용해도 전체 역사적 구성종목 재현을 보장하지 않는다.
3. KRX 거래대금·거래량의 집계 범위는 미확인이다. OHLC 범위를 벗어난 VWAP을 강제 보정하지 않고 건수·날짜를 기록한다.
4. `RegularSessionUnavailable`은 정규장 OHLC 미관측 사실이다. 정규화의 `Trading_Halt` 실행 제외 표시와 구분한다. 원본 `RawVolume`·`Amount`는 남기고 실행용 `Volume`만 0으로 둔다. 공식 거래정지를 입증한 표시로 해석하지 않는다.
5. 수급 ranking의 미반환·부분 응답은 결측이다. 0으로 채우지 않는다. 현재 로컬 serving의 수급 H5/H20은 필요한 9개 수급 입력 중 하나라도 결측이면 해당 종목·기간의 추론을 제외한다. 기본 모델과 평가 표본이 달라 직접적인 효과 비교에 제한이 있다.

거래일 누락·불명확한 가격 결측은 추정 거래정지나 0으로 바꾸지 않고 거부한다. 정량 출력은 결정론이며 스코어·기여도·과거 사례는 미래 수익 보장이 아니다. 재점검 신호는 **매도 지시가 아님**을 화면에 함께 표시한다.

과거의 “KRX 날짜 전수 감사 대기”, “실제 VWAP 학습 입력 동등성 미확인” 경고는 전체 v3 가격·피처 대조와 공통 달력 검증이 통과한 새 pack에서만 해제한다. 상세 근거와 실제 제외 수는 [local-pack-validation.json](local-pack-validation.json)에 기록한다. 위 다섯 제한은 계속 남는다.
