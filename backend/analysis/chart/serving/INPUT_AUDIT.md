# 2026-09-25 차트 서빙 입력 자료 점검

## 점검 범위와 확인된 사항

다음 명령으로 H5·H20 학습 설정, 과거 예측 캐시, fold별 모델 14개, 공식 KOSPI 거래일 달력, 종목별 상장·상장폐지 기간 자료를 점검했다.

```bash
python -m serving.artifacts --out /tmp/chart-serving-full/input_manifest.json
```

각 기간의 과거 예측 캐시는 `Date`, `Code`, `Prob`로 이루어진 1,436,361행이다. 예측일 범위는 2019-01-07~2025-12-31이며, 각 행은 당시 저장된 fold 모델 하나에 연결된다. 캐시 식별자는 기간별로 구분되고, 일곱 fold 모델의 피처명·순서와 3개 분류 출력 구성이 일치했다. 예측일이 해당 종목의 상장·상장폐지 기간 안에 있는지도 통과했다.

학습 입력에 들어 있는 배리어 피처는 Sigma 배수 1.5/1.2를 사용한다. 이는 정답을 정하는 **라벨 배리어**와 다르다. 라벨 배리어는 H5가 1.75/1.50, H20이 3.75/3.00이다.

## 공개를 막는 문제 1: 휴장일 예측

| 예측 기간 | 캐시 식별자 | fold 모델 | 캐시 행 수 | 거래소 휴장일의 행 | 해당 휴장일 수 |
|---|---|---:|---:|---:|---:|
| H5 | `38753398` | 7개 | 1,436,361 | 82,701 | 103일 |
| H20 | `568d2288` | 7개 | 1,436,361 | 82,701 | 103일 |

예를 들어 2019-02-04는 거래소 휴장일이다. 그런데 삼성전자(`005930`)의 기존 가공 입력에는 이 날이 거래량 0, `Trading_Halt=1`인 행으로 들어 있고, 과거 예측 캐시에도 이 날의 예측이 있다. 처음 확인된 날짜에는 2019-02-04~06과 2019-03-01이 포함된다.

거래소 전체가 쉰 날은 **개별 종목의 거래정지일이 아니다.** 따라서 이 예측을 공식 거래일 기준의 과거 사례 원장에 넣을 수 없다. 현재 `inspect_inputs(strict=True)`와 `validate_manifest`는 H5·H20 모두 거부하며, 공개용 release는 만들지 않았다. 원본 캐시를 덮어쓰거나 문제 행을 조용히 사례에 포함하지 않는다.

## 확인한 범위와 남은 복원 작업

진단 목적으로 삼성전자의 2025년 마지막 fold 모델로 해당 fold의 H5·H20 출력을 다시 계산했다. 각 기간 257행에서 모델의 상방(class 2) 출력이 기존 캐시의 `Prob`와 정확히 일치했다. 2019년 fold 하나도 기간별로 같은 결과를 확인했다.

이는 **일부 fold의 모델·캐시 연결 확인**일 뿐, 전체 자료의 검증 완료를 뜻하지 않는다. 휴장일 입력 문제를 바로잡은 뒤 14개 fold 전체의 하방·중립·상방 출력을 당시 모델로 복원하고, 기존 상방 출력과 대조해야 한다.

## 공개를 막는 문제 2: 실제 VWAP과 최신 입력

현재 `data/raw`에는 실제 거래대금과 거래량으로 계산한 VWAP(거래량 가중 평균가격) 입력이 없다. `data/processed`도 2026-06-12까지만 있다. 서비스 피처는 수정주가 기준의 실제 VWAP을 사용해야 하며, 임의로 만든 값으로 대체할 수 없다.

따라서 새로 만든 서비스 피처가 학습 당시 입력과 같은지 확인한 보고서가 없고, 최신 확정일 삼성전자 H5·H20 결과도 없다. 이 검증이 끝나기 전에는 release 활성화와 일일 배치 공개를 막는다.

## 다음 작업 순서

1. 공식 거래일을 기준으로 과거 가공 입력과 H5·H20 OOS 예측을 다시 만들고, 휴장일 예측이 사라졌는지 검사한다. 기존 캐시는 보존한다.
2. 각 과거 예측을 당시 fold 모델과 연결해 3개 분류 출력을 복원한다. 상방 출력은 기존 `Prob`와 허용 오차 `rtol=1e-6`, `atol=1e-8`로 대조한다.
3. 실제 거래대금 기반 VWAP이 포함된 원천 일봉을 확보하고, 서비스에서 재계산한 피처가 학습 입력과 같은지 검증한다.
4. 검증된 과거 사례 원장과 H5·H20 release를 만든 뒤에만 일일 배치의 공개를 진행한다.

이 문서는 **입력 자료의 검사 결과**다. DB migration 적용, 프론트 배포, 첫 공개 배치 확인은 별도 운영 단계이며 현재 완료 증거가 없다.
