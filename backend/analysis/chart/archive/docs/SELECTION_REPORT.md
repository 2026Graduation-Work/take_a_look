# 실험 결과 비교 분석 보고서

작성 기준일: 2026-06-29
대상 전략: `prob_up` 기반 top-k long-only 스윙 전략
주요 평가 관점: ML 분류 성능 자체보다, `prob_up` 랭킹이 실제 포트폴리오 수익으로 연결되는지 검증

## 1. 평가 기준

이 프로젝트의 모델은 모든 종목의 `up / neutral / down`을 정확히 맞히는 일반 분류기가 아니라, 매일 `prob_up`이 높은 종목을 골라 5~20일 보유하는 랭킹형 스윙 전략이다. 따라서 지표 해석 우선순위는 다음과 같다.

| 우선순위 | 지표 | 해석 기준 |
|---:|---|---|
| 1 | fold별 수익률 | 여러 시장 구간에서 반복적으로 수익이 나는가 |
| 2 | holdout 성과 | 후보 선택에 쓰지 않은 2024년에서도 살아남는가 |
| 3 | benchmark 대비 성과 | 시장 상승 덕이 아니라 모델/전략의 초과수익인가 |
| 4 | MDD | 손실 구간이 실전적으로 감당 가능한가 |
| 5 | Sharpe / Sortino | 수익이 변동성 대비 효율적인가 |
| 6 | profit factor / win rate | 거래 구조가 우연이 아니라 기대값을 가지는가 |
| 7 | 거래 횟수 | 표본 수가 충분한가 |
| 8 | ML metric | ranking signal의 품질을 보조적으로 확인 |

중요한 해석 원칙:

- `accuracy`나 `balanced_accuracy`가 0.50 근처라고 해서 전략이 곧바로 무효는 아니다.
- top-k 전략에서는 전체 샘플 분류 정확도보다 상위 확률 구간의 ranking 품질이 중요하다.
- 반대로 ML metric이 낮은데 백테스트만 좋다면 leakage, 특정 구간 과최적화, 특정 종목 집중 여부를 반드시 확인해야 한다.

## 6. H5 `u175/d150` vs H20 `u375/d300`

최종적으로 비교해야 할 후보는 두 개다.

| 항목 | H5 `u175/d150` | H20 `u375/d300 full` | 해석 |
|---|---:|---:|---|
| Total Return | 126.44% | 95.86% | H5 우위 |
| CAGR | 22.18% | 17.91% | H5 우위 |
| Sharpe | 1.088 | 0.991 | H5 소폭 우위 |
| Sortino | 1.381 | 1.317 | H5 소폭 우위 |
| MDD | -15.12% | -15.26% | 유사 |
| Trades | 827 | 677 | H5가 더 빈번 |
| Win Rate | 51.51% | 47.56% | H5 우위 |
| PF | 1.276 | 1.309 | H20 소폭 우위 |
| 양수 Fold | 4/4 | 4/4 | 동률 |
| 2024 Return | 5.89% | 1.87% full 기준 / 5.48% holdout 기준 | H5 또는 유사 |

해석:

- 순수 성과와 Sharpe 기준으로는 H5 `u175/d150`이 더 낫다.
- H20 `u375/d300`은 수익률은 낮지만 PF가 소폭 높고, horizon 확장 후보 중 유일하게 robustness를 통과했다.
- H20 full의 2024 return이 1.87%이고 holdout 단독 결과가 5.48%인 차이는 실행 config/fold 구성 차이에서 생긴 것으로 보인다. 최종 비교 전 동일 config 기준 재검증이 필요하다.
- H5는 더 짧은 보유 기간과 더 많은 거래를 통해 성과를 만든다.
- H20은 더 긴 보유 기간과 낮은 거래 빈도로, 신호가 느리지만 비교적 안정적인 대안이다.

- 최종 평가는 ML metric이 아니라 top-k portfolio 성과와 fold 안정성으로 해야 한다.

## 8. Benchmark 해석

Benchmark 관련 주의점:

- 일부 과거 selection 결과는 `benchmark_custom_krx_source`가 `None`이거나, 이전 실행에서 `0.00% / NaN`으로 찍힌 적이 있다.
- holdout/full/robustness 일부 결과는 `external_krx` 기준으로 정상 기록되어 있다.
- 따라서 selection 구간의 benchmark 대비 판단은 신중해야 하며, 최종 후보 2개는 동일 benchmark 로직으로 재산출하는 것이 좋다.

확인 가능한 2024 benchmark 기준:

| 구간 | Benchmark Return | 후보 | 후보 Return | 초과수익 |
|---|---:|---|---:|---:|

| 2024 | -9.70% | H10 `u250/d225` | -0.04% | +9.66% |
| 2024 | -9.70% | H20 `u375/d300` | 5.48% | +15.18% |

해석:

- 2024에는 대부분 benchmark보다 방어를 잘했다.
- 하지만 H10은 benchmark 대비로는 좋지만 절대수익이 거의 0이라 최종 채택 근거로는 약하다.
- H20 `u375/d300`은 benchmark 대비와 절대수익 모두 양수라 가장 설득력이 있다.
